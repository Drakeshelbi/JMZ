DRAKE.. | DBA Reporte de SQL Server: 3 Años de Logros

Introducción

Este documento describe todas las actividades realizadas en el entorno de SQL Server durante los últimos 3 años, incluyendo implementaciones de alta disponibilidad, optimizaciones de consultas y configuraciones de clúster.

Grupos de Alta Disponibilidad

Implementamos grupos Always On para garantizar la continuidad operativa 24/7. Estos esfuerzos incluyeron la configuración de failover clusters y la creación de listeners dedicados.

Configuración de Always On y failover clustering.

Optimización de Consultas

Se optimizaron consultas SQL utilizando índices y planes de ejecución avanzados, logrando reducciones significativas en tiempos de respuesta.

Gráfico de rendimiento tras optimizaciones.

Migraciones y Actualizaciones

Realizamos migraciones de versiones antiguas a SQL Server 2022, asegurándonos de preservar la integridad y disponibilidad de los datos.

Proceso de migración de SQL Server.

La práctica nos ayuda a construir mejores experiencias en diferentes entornos.
